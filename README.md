# abhijit-s/homebrew-tap

Personal Homebrew tap.

## Install

```bash
brew tap abhijit-s/tap https://github.com/abhijit-s/homebrew-tap.git
```

## Available formulas

| Formula | Description | Source |
|---|---|---|
| `fff` | Fast frecency-ranked file finder MCP server | [abhijit-s/fff](https://github.com/abhijit-s/fff) |

## Usage

```bash
brew install abhijit-s/tap/fff
```

## Maintenance

Formulas in this repo are kept in sync with their source projects' tagged releases.
Each formula links back to its source repo in its `homepage`.
